技术支持

2026-10-08 更新

提醒没有按时响

  • 检查系统是否给了通知权限：设置 → 通知 → 超能待办（Tallyon）。
  • 关闭「专注模式 / 勿扰模式」，或把本应用加入允许列表。
  • 当天目标已达成时，应用会自动静音当天剩余提醒（这是设计如此，避免重复打扰）。
  • 确认「我的 → 通知总开关」没有被关掉。

换设备后数据没同步

  • 在两台设备的「设置」里登录同一个 Apple ID 并开启 iCloud。
  • 在「我的 → iCloud 同步」手动触发一次。
  • 同步以最后写入为准，不做冲突合并；如果另一端是更新版本写的，本机读不出来时会保留原样不覆盖。

订阅恢复

  • 「我的 → 升级 Pro → 恢复购买」，用同一 Apple ID 恢复即可，不会重复扣费。
  • 若提示找不到购买记录，请确认登录的是购买时用的那个 Apple ID。
  • 取消续订：iOS「设置 → Apple 账户 → 订阅」中选择本应用并取消。

桌面小组件 / 锁屏实时活动没有出现

  • 小组件需要 iOS 16.2 及以上，长按主屏幕 → 左上角 ➕ → 搜索本应用添加。
  • 添加后若一直空白，打开一次 App 即可刷新数据。

数据导入或备份

已经写好的清单可以用「我的 → 批量导入」一次性导入（支持一行一条的纯文本，或 Excel / Numbers 导出的 CSV、TSV）。数据保存在本机与你的 iCloud 中，可用 iPhone 的系统备份覆盖。
