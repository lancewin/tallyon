服务内容

超能打卡清单（Tallyon）为你提供打卡记录、待办清单与专注计时的工具。应用按「现状」提供，不保证达成任何特定的自律效果。

账号

本应用不提供注册与登录，也不设账号体系，因此不存在账号注销、账号找回等问题。

免费额度与 Pro

  • 免费版：最多 3 个打卡项，每项每天最多 3 次提醒。
  • Pro：解锁无限打卡项、每天最多 10 次提醒、隐私锁（Face ID / 密码）。
  • 统计报表、iCloud 同步与全部主题对免费版同样开放，不需要订阅。
  • 价格以 App Store 展示为准（可能为当地货币）。

订阅、试用与退款

  • Pro 为自动续订订阅，按年计费，含 3 天免费试用。
  • 试用期内取消不扣费；订阅期内取消，当期结束后不再续订。
  • 订阅会在当前周期结束前 24 小时内自动续订，费用由 Apple 从你的 Apple ID 账户扣除。
  • 退款由 Apple 处理，请通过 App Store 的购买记录提交申请。
  • 已购买的订阅可在应用内「恢复购买」找回，不会重复扣费。
  • 取消方式：「设置 → Apple ID → 订阅」。
